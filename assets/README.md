# Assets

| Folder | Holds | Name pattern |
| --- | --- | --- |
| `img/` | photographs and figures shown on the page | `<subject>.<ext>` |
| `icons/` | link icons in the header | `<service>.svg` |
| `slides/` | talk slides | `<project>-<duration>-<venue>-<year>.pdf` |
| `posters/` | conference and workshop posters | `<project>-<venue>-<year>.pdf` |
| `teaching/` | lecture slides | `<unit>-part-<n>-<year>.pdf` |
| `docs/` | everything else | `<subject>.pdf` |

Names are lowercase, words separated by hyphens, and the year is the year the
talk was given rather than the year the file was written.
